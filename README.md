# TimeMini - 倒计时桌面应用规格文档

## 1. 项目概述

- **项目名称**: TimeMini
- **类型**: Go桌面应用 (Wails + React)
- **核心功能**: 倒计时、统计、TodoList三大功能
- **目标用户**: 学生、程序员、作家等需要时间管理的人群

## 2. 技术架构

### 前端

- **框架**: React + TypeScript
- **UI库**: Ant Design / 自定义组件
- **状态管理**: React Context + Hooks
- **样式**: CSS Modules / Styled Components

### 后端

- **框架**: Wails (Go)
- **数据库**: SQLite (嵌入式，无需额外安装，比MySQL更适合桌面应用)
- **ORM**: GORM

### 系统集成

- 系统托盘
- 桌面通知
- 开机启动
- 全局快捷键

## 3. 功能规格

### 3.1 倒计时功能

#### 预设时间

- 番茄钟: 15, 20, 25, 30, 45 分钟
- 自定义时间: 1分钟 - 24小时

#### 用途分类（可自定义）

- 学习
- 码字
- 编程
- 运动
- 休息
- 其他（自定义）

#### 倒计时模式

- 单次倒计时
- 循环倒计时（可设置循环次数）
- 正计时（记录时长）

#### 倒计时控制

- 开始/暂停/停止
- 剩余时间显示
- 完成提示（声音+通知）

### 3.2 统计功能

#### 统计维度

- **当天统计**: 今日总时长、各用途分布
- **周统计**: 本周每日时长、对比上周
- **月统计**: 本月总时长、日/周分布
- **年统计**: 本年总时长、月度趋势
- **全统计**: 所有历史记录汇总

#### 展示方式

- 数字显示（总时长）
- 图表展示（柱状图、饼图）
- 列表详情

### 3.3 TodoList功能

#### 任务管理

- 创建任务（标题、描述、用途类型）
- 设置倒计时任务（关联倒计时）
- 标记完成
- 删除任务
- 编辑任务

#### 任务状态

- 待开始
- 进行中
- 已完成

#### 任务筛选

- 全部
- 进行中
- 已完成

## 4. 界面设计

### 整体风格

- 现代简约风
- 深色/浅色主题切换
- 圆角卡片设计
- 平滑动画过渡

### 布局

- 左侧导航栏（可折叠）
- 顶部标题栏
- 主内容区域

### 颜色方案

- 主色: 蓝色系 (#1890ff)
- 背景: 深灰(#1a1a2e) / 浅灰(#f5f5f5)
- 强调色: 橙色(番茄钟)
- 文字: 白/黑

## 5. 数据结构

### TimerRecord (计时记录)

```
id, user_id, purpose, duration, start_time, end_time, is_completed, created_at
```

### Todo (待办事项)

```
id, user_id, title, description, purpose, timer_duration, status, completed_at, created_at
```

### Purpose (用途分类)

```
id, name, color, icon, is_default, created_at
```
